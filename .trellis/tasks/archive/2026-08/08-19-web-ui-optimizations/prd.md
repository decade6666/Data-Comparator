# Web UI 六项优化：进度条/表单持久化/下载鉴权/导出清理/配置改项目/设置弹窗

## Goal

修复 Web UI 六项问题：上传后进度条卡住、表单扫描结果刷新丢失、下载/上传报"未授权"、导出未清空文件引用且无提示、「配置管理」改名「项目管理」、修改密码/退出登录移入设置弹窗。

## Requirements

### 1. 去掉上传/扫描进度条

- 进度条只反映比对任务真实进度；空闲（含扫描期间）归零。
- 扫描期间保留「扫描文件中…」文字提示；「开始比对」按钮在扫描期间保持禁用。

### 2. 表单扫描结果持久化（存服务器，项目数据中）

- 扫描到的表单名随项目数据保存到服务器（项目 JSON 文档），刷新恢复项目后自动还原，「编辑比对表单」「表单顺序」有内容。
- 用户已确认：不用 localStorage 缓存，方案为「存在服务器，项目的数据中」。

### 3. 修复下载报 "未授权"

- `useJob.download()` 与 `ConfigSidebar.exportCurrent()` 的 `window.open` 改为带鉴权头的 fetch → blob → `<a download>` 通道。

### 4. 导出时清空文件引用 + 弹窗提醒

- 导出前弹窗提醒「不包含已上传的比对文件」；导出 JSON 剔除文件引用字段（`old_file_path` / `new_file_path` / `old_file_upload_id` / `new_file_upload_id` / 表单字段）。

### 5. 「配置管理」改名「项目管理」

- 所有用户可见的「配置」（指"保存的项目预设"概念）改为「项目」，含前端按钮/弹窗/提示/帮助文档与后端 HTTP detail 中文文案。
- **不改**：API 路由、payload key、JS 符号名/文件名、CSS 类名、localStorage key；「内置模板」「配置项功能说明」语义不同不改。

### 6. 修改密码/退出登录移入设置弹窗

- `AdvancedSettingsDialog` 内直接放两个按钮，左「修改密码」右「退出登录」，无文字说明。
- 顶栏移除这两个按钮；管理员顶栏补「设置」按钮并挂载弹窗（管理员隐藏「最大线程数」行）。

## Acceptance Criteria

- [ ] 上传+扫描后进度条归零，比对时显示真实进度；扫描期间显示「扫描文件中…」且开始按钮禁用
- [ ] 扫描表单 → 保存项目 → 刷新 → 恢复项目后，「编辑比对表单」「表单顺序」仍显示表单名
- [ ] 「下载报告」「导出项目」正常下载，不再报「未授权」
- [ ] 导出前弹窗提示；导出 JSON 不含文件引用/表单字段
- [ ] 界面与接口错误文案「配置」→「项目」全部完成；前后端测试全绿（改名断言同步更新）
- [ ] 设置弹窗内有「修改密码」「退出登录」两按钮；顶栏移除；管理员可打开设置弹窗

## Notes

- `CompareRequest` 为 `extra: "forbid"`：新字段必须从任务提交 payload 剔除。
- 测试覆盖不得下降；现有前后端测试必须全部通过。
