# 开发文档

本文档面向研发/维护者，介绍架构、关键模块、数据流、扩展点与测试要点。

## 架构概览
- Web/API 层（`src/frontend/web_api.py`）：FastAPI 请求/响应边界，调用应用层服务
- 前端运行时层（`src/frontend`）：Web API 服务与前端辅助能力
- 后端应用层（`src/backend/application`）：框架无关比对编排、路径校验、输出路径生成与处理前参数组装
- 后端领域层（`src/backend/domain`）：Excel 读取、差异检测、写回高亮与停止控制
  - `data_comparison.py`：流程编排、并发、多表/单表处理、差异聚合
  - `excel_header_utils.py`：头部行（SASFieldLabel）/锚点行（SASFieldName）读取
  - `excel_utils.py`、`highlight_optimizer.py`：表头替换、Sheet/单元格高亮
- 后端基础设施层（`src/backend/infrastructure`）：配置、进度、临时目录与文件预处理等运行时适配
- 共享层（`src/shared`）：跨层契约与日志转发

依赖管理使用 `pyproject.toml`，可选 extras：`performance`、`dev`。

## 运行入口
- `src/main_web.py`：读取 `DATASET_COMPARATOR_WEB_HOST` / `DATASET_COMPARATOR_WEB_PORT` 环境变量，通过 Uvicorn 加载 `src.frontend.web_api:app`

## 配置与持久化
- 参数由 `JsonParameterRepository` 管理，存于 AppData：`PyDataCompare/temp/configs/<配置名>.json`
- 内置配置模板定义在 `parameter_templates.py`，由 `ensure_builtin_templates` 创建，模板受保护不可覆盖
- 关键参数结构（示例）：
```json
{
  "old_file_path": "",
  "new_file_path": "",
  "output_directory": "",
  "anchor_row_num": 1,
  "header_row_num": 1,
  "max_workers": 7,
  "merge_deleted_data": true,
  "common_cols": [],
  "exclude_sheets": [],
  "default_keys": [],
  "sheet_key_map": {},
  "include_sheets": [],
  "ignore_cols": [],
  "sheet_ignore_cols": {},
  "sheet_order": [],
  "colors": {
    "highlight_fill": "#FFE5E5",
    "missing_sheet_tab": "#DC143C",
    "new_sheet_tab": "#00FF00"
  }
}
```
- 运行期整合到 `ConfigManager.update_from_parameters`，并将颜色转为 openpyxl `PatternFill`

## 数据流与核心流程
- Web/API 收集参数 → 应用层校验路径与输出位置 → 初始化 `ThreadSafeProgressManager`/`ConfigManager`
- 预处理：
  - `check_and_remove_file_protection`：复制到 AppData/temp，移除 Zone.Identifier，清理 AutoFilter，按需删除 `exclude_sheets`
  - `validate_excel_file`：多引擎快速验读
- 逐 Sheet 流程（线程池执行）：
  - `read_single_sheet_from_excel`：一次性只读目标 Sheet；解析 `SASFieldLabel/Name`，生成 `attrs`（列名/标签/映射）
  - 缺失/新增分支：`process_missing_sheet` / `process_new_sheet`
  - 正常比对：
    - `create_anchor_by_sas_names` 生成 `_ANCHOR`
    - 外连接合并 `_ANCHOR`，旧列后缀 `_OLD_`
    - `compare_columns_by_sas_names` 产出单元格 diff 明细（忽略字段在此单点过滤）
    - 汇总“新增/删除/更新”并写入“更新情况（标记）”列
  - 写回：使用 `src.backend.domain.excel_utils.apply_highlight_to_worksheet` 进行表头/单元格/整行高亮
- 输出表单顺序：`process_edc_multithreaded` 在创建“比对结果汇总”Sheet 前按 `sheet_order` > `include_sheets` > 源文件顺序重排
- 资源回收：条件 GC `_maybe_gc_collect`，并在 finally 更新 Sheet 状态

## 线程与停止机制
- 线程池大小：`ConfigManager.max_workers`，默认 `max(1, cpu_count()-1)`
- 停止：`threading.Event` + `processing_control.check_stop_frequently` 在关键循环中主动抛出 `InterruptedError`；Web/API 层将 `InterruptedError` 映射为 HTTP 409
- 进度：`ThreadSafeProgressManager.update_sheet_progress` 更新进度回调

## 扩展点
- 比对策略：在 `perform_full_comparison` 中扩展匹配与差异规则
- 表头解析：`read_single_sheet_from_excel` 可支持更多头部布局或多行表头合并
- 高亮策略：`excel_utils.apply_highlight_to_worksheet` 可扩展色彩/样式规则
- 导入导出：在 `parameter_repository.py` / `parameter_templates.py` 增加 JSON Schema 校验与版本迁移
- 大表拆分：`BigSheetSplitConfig`（旧版参考）可逐步引入更细粒度分块

## 日志与临时文件
- 控制台打印 + 日志回调（转发至 `progress_manager.safe_log`）
- `_nofilter_`、`excel_extract_*` 均位于 AppData/temp；提供 `cleanup_nofilter_files` 清理

## 测试要点
- 大小混合：空 Sheet、有合并单元格、非标准表头、长列名、重复列名
- 受保护来源：Zone.Identifier 删除失败的回退行为
- 比对范围与顺序：`tests/test_compare_scope_and_order.py` 覆盖 include_sheets / ignore_cols / sheet_order 行为
- 性能回归：线程数变化、超大 Sheet、diff 覆盖路径
- 颜色正确性：表头新增/删除标识、更新单元格高亮

## 已知限制/注意
- `xlrd` 不支持 .xlsx；尽量使用 openpyxl
- 非结构化表头需手动指定表头/锚点行
- 忽略比对字段（ignore_cols）仅影响差异判定，不影响列输出与列增删检测

## 代码风格
- 参照 `pyproject.toml` 中的 black/isort 配置
- 命名/早返回/错误处理见仓库统一规范
