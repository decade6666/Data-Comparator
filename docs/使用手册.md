# 使用手册

本手册面向业务/测试/实施人员，讲解如何使用“数据集对比”Web/API 服务完成跨版本 Excel 数据差异比对，并生成可视化高亮结果。

## 一、启动服务

Web/API 服务通过环境变量配置监听地址与端口：

- `DATASET_COMPARATOR_WEB_HOST`：监听地址，默认 `0.0.0.0`
- `DATASET_COMPARATOR_WEB_PORT`：监听端口，默认 `8888`

启动方式：

```bash
# 方式一：已安装项目脚本
DATASET_COMPARATOR_WEB_HOST=0.0.0.0 DATASET_COMPARATOR_WEB_PORT=8888 dataset-comparator-web

# 方式二：模块方式
DATASET_COMPARATOR_WEB_HOST=0.0.0.0 DATASET_COMPARATOR_WEB_PORT=8888 python -m src.main_web
```

首次运行会在用户数据目录创建临时与配置子目录，例如：

- 配置目录：`PyDataCompare/temp/configs`
- 日志与中间文件：`PyDataCompare/temp`

## 二、健康检查与比对请求

### 健康检查

```bash
curl http://127.0.0.1:8888/health
```

返回 `{"status": "ok"}` 表示服务正常。

### 发起比对

```bash
curl -X POST http://127.0.0.1:8888/api/compare \
  -H 'Content-Type: application/json' \
  -d '{
    "old_file_path": "/data/old.xlsx",
    "new_file_path": "/data/new.xlsx",
    "output_directory": "/data/output"
  }'
```

成功后返回结果文件路径：`{"output_path": "/data/output/...xlsx"}`。

### 参数一览

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| old_file_path | string | 是 | 旧版本 Excel 文件路径 |
| new_file_path | string | 是 | 新版本 Excel 文件路径 |
| output_directory | string | 是 | 输出目录，结果文件存放于此 |
| config_name | string | 否 | 配置名，用于生成输出文件名（默认 `web`） |
| anchor_row_num | integer | 否 | 锚点行号（默认 1） |
| header_row_num | integer | 否 | 表头行号（默认 1） |
| merge_deleted_data | boolean | 否 | 是否把删除的表单/行写入结果（默认 true） |
| common_cols | array | 否 | 排除字段（全局）：读取时直接丢弃、不参与比对和输出的列 |
| sheet_common_cols | object | 否 | 排除字段（指定表单）：整体替换全局排除字段（不是追加合并）；未命中的表单回退到全局 common_cols |
| exclude_sheets | array | 否 | 完全不参与比对的 Sheet 名称 |
| default_keys | array | 否 | 所有表单的通用锚点列 |
| sheet_key_map | object | 否 | 为特定 Sheet 覆盖默认锚点（优先级高于默认锚点） |
| include_sheets | array | 否 | 指定表单：非空时只比对/输出列表内的表单；与 exclude_sheets 同时存在时先 include 后 exclude |
| ignore_cols | array | 否 | 忽略比对字段（全局）：字段照常输出，但不产生差异、不高亮、不影响行级标记、不计入汇总 |
| sheet_ignore_cols | object | 否 | 按表单覆盖全局忽略字段：整体替换语义（不是追加合并）；未命中的表单回退到全局 ignore_cols |
| sheet_order | array | 否 | 输出表单顺序：优先级 sheet_order > include_sheets > 源文件顺序 |
| colors | object | 否 | 更新/新增/删除内容的标记颜色 |

颜色配置示例：

```json
"colors": {
  "highlight_fill": "#FFE5E5",
  "missing_sheet_tab": "#DC143C",
  "new_sheet_tab": "#00FF00"
}
```

## 三、输出结果说明

- 结果文件为 Excel 工作簿：
  - 第 1 列固定为“更新情况（标记）”
  - 新增/删除表单：整表单行高亮；Sheet 标签颜色区分
  - 更新行：仅高亮发生变动的单元格
  - 列增删：表头颜色标注（新增用“新增色”，删除用“缺失色”）
- 表单排列顺序：默认按源文件顺序（新文件为主，旧文件独有表单追加在后）；配置 `sheet_order` 后按指定顺序；仅配置 `include_sheets` 时按列表内顺序
- 忽略比对字段（`ignore_cols` / `sheet_ignore_cols`）：对应列照常输出在结果文件中，但其变化不产生差异、不高亮、不影响行级更新标记、不计入汇总统计
- 命名与位置：结果文件存放于“输出目录”；对照服务日志可查看处理详情

## 四、常见问题与排错

- 服务无法启动：确认端口未被占用，环境变量拼写正确
- 文件打不开/无权限：确认服务进程对输入文件与输出目录有读写权限
- 表头与锚点识别错误：调整 `anchor_row_num` / `header_row_num`，避免 `SASFieldName` 重复
- 大文件慢/爆内存：降低最大线程数（max_workers）；关闭其它占内存程序；确认磁盘空间
- xls 格式：请转换为 .xlsx 或 .xlsm
- 输出无高亮：确认“更新情况（标记）”列存在
- 比对被停止：任务被用户主动停止时 API 返回 HTTP 409；停止后残留临时文件可手动清理（用户数据临时目录）
